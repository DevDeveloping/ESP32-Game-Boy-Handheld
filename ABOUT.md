# About

This is a DIY monochrome Game Boy handheld built around an ESP32-WROOM-32, a 240 x 320 ILI9341 SPI display, and a Bluetooth controller or optional wired pushbuttons.

The project is special because it runs on inexpensive microcontroller hardware without PSRAM or a Raspberry Pi. It uses Peanut-GB and memory-mapped flash for game ROMs, stores saves in flash, and offers two practical setups: an SD-card launcher for multiple games or a single-game build that does not need an SD card after flashing.

The firmware targets original monochrome Game Boy games. It is an educational embedded project for learning how an emulator, display, controller, removable storage, and save system fit together on a resource-limited board.

Game ROMs, saves, and artwork are not included. Use only game files you are legally allowed to use.
